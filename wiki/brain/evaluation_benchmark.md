# 32 题 RAG 与防幻觉基准评测 (Evaluation Benchmark)

为了严谨量化明日方舟专用 RAG 语料库的检索质量以及防幻觉闸门对虚假实体的拦截能力，本项目构建了一套包含 **32 道高难度评测题目** 的基准测试集，并在本地测试套件中实现了完全自动化的回归验证。

---

## 1. 评测集设计原则与题型分布

评测集被划分为四大类别的真实业务场景，其中包含 **7 道专门诱导大模型产生幻觉的陷阱题**：

```text
+--------------------------------------------------------------------------------------------------+
|                                32 题评测基准题型分布全景                                          |
+------------------------------------+-------------------------------------------------------------+
| 类别 1: 关卡刷图与产出攻略 (Q01~Q08)| 测试关卡 1-7, CE-6, LS-6, CA-5, AP-5, SK-5, 剿灭与地图尺寸    |
| 类别 2: MaaMeow 配置与 Schema (Q09~Q16)| 测试 8 类核心 TaskTypeInfo 字段名与参数结构语义              |
| 类别 3: 干员/材料/作业规范 (Q17~Q25)| 测试真实干员 ID (银灰/玛恩纳/维什戴尔/黍/桃金娘) 与材料字典  |
| 类别 4: 防幻觉陷阱拦截测试 (Q26~Q32)| 测试虚构关卡 (99-99/CE-99/PR-Z-9)、虚构干员与未知材料 ID 拦截 |
+------------------------------------+-------------------------------------------------------------+
```

## 3. 评测方法论与检索索引架构

基准测试运行器（`scripts/eval_rag_benchmark.py`）采用了 **双通道混合分词检索索引 (`HybridChunkIndex`)**：

1. **中文与英文混合分词**：对所有中英文字符、下划线以及连续汉字进行 n-gram（含 1-gram 与 2-gram 窗口）切词；
2. **BM25 词频统计与逆文档频率 (IDF)**：
   $$score(D, Q) = \sum_{i=1}^{n} IDF(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{avgdl})}$$
   其中设置饱和参数 $k_1 = 2.2$，$b = 0.75$；
3. **实体增强权重 (Entity Boosting)**：
   若 Chunk 中的 `entity` 字段完整出现在用户 Query 中，赋予高达 `+18.0` 的额外强权加分；若 Chunk 属于核心指南或 Schema，额外施加 `1.25x` 权重倍率；
4. **防幻觉判定**：对于陷阱问题，直接由实体校验网关截断并判定是否正确返回了拒绝状态。
